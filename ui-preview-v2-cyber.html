Cyberpunk + Glassmorphism Fusion — Key Decisions

  • Grid background — subtle 32px grid lines give "mission control" feel without noise
  • Top-edge glow — glass cards have a gradient glow line at the top edge (::before pseudo)
  • Cyan accent — neon cyan (#22d3ee) for active/executing states, contrasts with purple primary
  • Glow shadows — status dots and active elements have colored box-shadows for neon effect
  • JetBrains Mono — all data, stats, counters, headers use monospace for tech density
  • Deeper blacks — bg-primary is #080612 (bluer-black) vs current #0f0a1a
  • Role badges with borders — subtle 1px colored borders on role badges add depth
  • Proposal card glow — accent-bordered card with box-shadow glow draws attention to decisions
  • No glass nesting — inner elements are flat; only top-level cards use backdrop-filter
  • Pulse animation — executing status uses a slow 2s pulse on the cyan dot

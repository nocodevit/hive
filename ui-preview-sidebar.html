1 · Butler is not a project

Butler and Overview sit in their own card at the top: things for all of Hive. Butler shows how many items wait for you. The project tree starts below the "Projects" label.

2 · Projects open in place

Same as Claude: the chevron opens a project and its agents show under it. The Agents pane goes away, so the terminal gets about 200px more.

3 · What opens by itself

The current project, plus any project with an agent that needs you, starts open. A project where every agent is off starts closed and says "4 off". Inside an open project, off agents are dimmed.

4 · Status on one line

Each agent row shows avatar, dot, name, then "needs you" (amber) / "working" (green) / time since. Collapsed projects keep amber and green counts. Hover shows ＋ new agent on the project and ⋯ on the agent.

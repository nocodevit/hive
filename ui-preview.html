Design Suggestions

Area Current Suggestion Why
Monospace font System mono fallback JetBrains Mono for stats/counters Aligns numbers, feels more technical
Todo layout 2-col glass cards (R&D / Admin) Single unified list with zone tags Scannable, sortable, shows cross-zone priority
Task Group agents Horizontal pill bar Vertical roster table with stats Shows dept, role, completion at a glance; scales to 10+ agents
Status indicators Color text only Small dots on avatars/icons Subtle but visible; matches macOS patterns
Spacing rhythm Mixed 1.5/2/3/4/5 gaps Standardize to 4px grid (8/12/16/24) Tighter visual rhythm, more data density
Glass effect usage Everywhere (cards, modals, status) Reserve glass for top-level containers only Glass-on-glass is noisy; flat inner elements read faster
Sprint counter None Per-agent task/sprint stats in roster Makes productivity visible; motivates balanced distribution
Color hierarchy Purple accent everywhere Purple for actions, secondary for data, muted for labels Reduces visual noise; accent stands out when it matters
